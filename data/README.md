# 数据放这里

## 怎么拿

下载：<https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip>（273 KB，**免注册**）

解压后把这三个文件放进**本目录**：

| 文件 | 说明 |
|---|---|
| `hour.csv` | 小时级数据，**本项目主用这个** |
| `day.csv` | 按天汇总，备查 |
| `Readme.txt` | 列含义的权威说明 —— **先读它** |
